## How to add a delivery

1. Export the .pptx → PDF with the conference name in the footer.
2. Save as `deliveries/<event-slug>/slides.pdf`.
3. Add a row to the table above.
4. Add a row to the `<table class="deliveries">` in `index.html`.

## Note on the canonical `slides.pdf`

`slides.pdf` at the root of this folder is intended to be the conference-neutral version of the deck (footer = generic, no event name). Today it's a copy of the Raleigh PDF — replace it with a neutral re-export when convenient.
