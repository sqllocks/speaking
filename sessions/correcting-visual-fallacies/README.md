# Now you see it, but did you really? Correcting visual fallacies

A speaking session by **Jonathan Stewart** · [sqlbites.net](https://sqlbites.net)

Charts mislead, sometimes by accident and sometimes by design. This session
walks the visual fallacies that quietly distort what an audience takes away
(truncated and dual axes, misleading area and 3D, cherry-picked ranges, colour
that lies) and shows how to correct each one so your visuals tell the truth, not
just a story.
