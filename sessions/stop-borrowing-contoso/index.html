Stop Borrowing Contoso

A speaking session by Jonathan Stewart · sqlbites.com

Build realistic demo data for Power BI. Contoso and Faker-style generators give you polite, evenly-spread rows that never look like real data and never break the way real data breaks. This session builds Spindle, an open-source, schema-aware synthetic data engine: profile the shape of real data (and only the shape ever leaves), then generate a statistical twin that keeps the distributions, the skew, and the ugly edge cases with zero customer rows and zero PII. Demos that look real, on data you're allowed to share.
