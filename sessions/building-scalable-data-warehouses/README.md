# Building Scalable Data Warehouses with Microsoft Fabric

A speaking session by **Jonathan Stewart** · [sqlbites.net](https://sqlbites.net)

How to design an enterprise data warehouse on Microsoft Fabric that scales from
day one instead of getting refactored under load: medallion architecture done
right, the Fabric T-SQL warehouse, partitioning and incremental load patterns,
and the semantic layer that sits on top.
