# Your Warehouse, Your Semantic Model

A speaking session by **Jonathan Stewart** · [sqlbites.com](https://sqlbites.com)

*Stop tuning measures. Fix the layer underneath.*

With Direct Lake, your Power BI model reads the warehouse's own Parquet files in
place: one copy of the data, zero refresh to schedule. How the warehouse stores
rows (MERGE, clustering, V-Order, snapshots) becomes directly visible in your
report's load time. We build the warehouse so the semantic model is fast by
construction, not by firefighting DAX after the fact.
